GONDWA v0.2 — The Living World (test build)

DEPLOY ON GITHUB PAGES
1. Download the ZIP and extract index.html using Files on iPhone.
2. In the Gondwa- repository, replace the existing root index.html with this index.html.
3. Ensure the name is exactly index.html, not index 2.html.
4. Open your GitHub Pages site and refresh.

v0.2 intentionally starts a new world with the same fixed island geography.

WHAT IS IMPLEMENTED
- Persistent individual animals for terrestrial vertebrates and Rhamphorhynchus.
- Spatial fish schools and invertebrate colonies.
- Basic energy, hydration, age, health, fear, stamina, injury, feeding and predation.
- Carcasses with edible biomass, scavenging, decay, disappearance and nutrient return.
- Wind, simplified scent, cloud/rain, tidal crossings, fire and terrain overlays.
- Species visibility filters and individual animal selection.
- Chronicle records with View on Map, zoom and historical sites.
- 30/90/180/365-day census events, export/import and local autosave.

IMPORTANT TEST BUILD LIMITATIONS
- The map is a more detailed synthetic field map, not a fully geographic erosion/hydrology model.
- Wind and scent are simplified; full cross-species tracking is incomplete.
- Tidal bridge appearance is simulated; complete individual tidal route planning is not.
- Collision-with-tree deaths, recorded pursuit trails and full historical replay are not yet implemented.
- Ecological balance is not scientifically validated; long runs may experience collapses.
- Not tested on physical iPhone; browser smoke tests passed in headless Chromium at 38 and 361 days.
- This file does not automatically update GitHub.
