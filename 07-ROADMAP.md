# Implementation roadmap

**M0 — Design baseline:** docs, decision register, scope, schemas, dependency audit. This package completes a first draft.

**M1 — Bootable foundation:** TypeScript/Vite browser shell, deterministic core, small fixtures, save, tests. This package includes a **minimal runnable M1 starter**, not full M1 acceptance.

**M2 — Authoritative movement:** position/edge pathfinding, transit state, capacities, fuel, simultaneous encounters, legal order reports.

**M3 — Physical logistics:** depot inventories, cargo units, atomic transfer, convoy routes, distribution, automation, interdiction accounting.

**M4 — Combat and occupation:** weapon compatibility, firing budget, recon, seeded combat, persistent battles, capture, retreat, siege and victory.

**M5 — Economy and AI:** production, recruitment, repair, objective planner, fog-respecting AI, difficulty tuning.

**M6 — Mobile beta polish:** onboarding, tactical map, touch controls, battle reports, save migrations, automated stress tests and balance.

**Release gate:** no Beta 0.1 label until all critical acceptance tests pass. Track defects and design changes in GitHub issues; do not merge features that violate invariants.
